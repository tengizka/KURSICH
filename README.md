# КУРСИЧ 🎓

Telegram Mini App в стиле Duolingo: короткие уроки, карта-путь, XP, серии дней (🔥), сердечки (❤️), награды и кудрявый мальчик в очках **Курсич** вместо птицы. Маскот полностью нарисован в SVG и меняет эмоции по ситуации (радость, задумчивость, праздник, «упс», гордость, сонливость и др.).

## Первый курс: «Финансовая грамотность 2026»

Курс по финансовой грамотности: сначала простая теория, потом вопросы и закрепление.

24 урока, 6 разделов:

1. **Деньги и бюджет** — правило 50/30/20, подушка безопасности, инфляция, ключевая ставка 14%
2. **Банки и сбережения** — вклады и АСВ (1,4 млн ₽), налог на вклады, цифровой рубль (старт 1.09.2026), кэшбэк и СБП
3. **Кредиты без боли** — ПСК, кредитная история, самозапрет на кредиты, «снежный ком» и «лавина»
4. **Инвестиции: старт** — риск и пирамиды, ОФЗ, ИИС-3, фонды без паники
5. **Налоги и вычеты** — НДФЛ 13–22% (2026), вычеты, самозанятость, ПДС (софинансирование до 36 000 ₽/год)
6. **Безопасность и пенсия** — дипфейки-2026, «безопасные счета», цифровая гигиена, финальный экзамен

## Технологии

- Vite + Vanilla JS, без тяжёлых зависимостей
- Telegram WebApp API (`ready/expand`, тема, BackButton, HapticFeedback)
- Прогресс, XP, серия и награды — в `localStorage`
- Маскот — чистый SVG (`src/mascot.js`), эмоции: idle, happy, think, celebrate, sad, oops, surprised, proud, sleepy, wink, love

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production в dist/
```

## Как подключить к Telegram

1. Дождись зелёного деплоя во вкладке **Actions** (сайт: https://tengizka.github.io/KURSICH/).
2. В [@BotFather](https://t.me/BotFather): `/newbot` → имя бота, например «КУРСИЧ».
3. Там же: `/setmenubutton` → выбери бота → отправь URL `https://tengizka.github.io/KURSICH/` → текст кнопки, например «🎓 Учиться».
4. Открой бота и нажми кнопку меню — мини-апп подхватит тему и пользователя Telegram, внутри будет работать тактильная отдача.
